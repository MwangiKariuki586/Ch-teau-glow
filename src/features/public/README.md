# Public Features

This folder contains all public-facing features accessible to all visitors.

## Features

- **landing** - Home page sections
- **about** - About us page
- **blogs** - Blog posts and articles
- **services** - Services catalog (coming soon)
- **shop** - Product shop (coming soon)
- **contact** - Contact page (coming soon)

## Usage

```tsx
import { HeroSection } from '@/features/public/landing';
import { AboutSection } from '@/features/public/about';
import { BlogList } from '@/features/public/blogs';
```
